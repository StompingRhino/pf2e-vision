# pf2e-vision — бриф

## Назначение
Удобный интерфейс для ГМ: в бою для каждого участника ползунком выставить его уровень видимости
относительно каждого другого участника. Результат влияет на то, что видят игроки на канвасе,
и на механику бросков.

## Окружение
- Foundry VTT **v14** (у пользователя ~14.360–14.364), система **pf2e 8.1.x**.
- Id модуля: `pf2e-vision`.
- Обязательная зависимость (`relationships.requires`): только `lib-wrapper`. Workbench и Toolbelt не требуются
  (решение 2026-10-11); с ними модуль совместим.
- Локально установлено, можно читать как справку по API:
  - система: `%LOCALAPPDATA%/FoundryVTT/Data/systems/pf2e/`
  - модули: `%LOCALAPPDATA%/FoundryVTT/Data/modules/{xdy-pf2e-workbench,pf2e-toolbelt,pf2ru-translation}/`
  - НЕ ИЗМЕНЯТЬ ничего в `Data/` — только читать.

## Пользователи
- Управляет ГМ (ползунки только у ГМ).
- Игроки видят результат: вид токенов на канвасе, эффекты в бросках.

## Уровни видимости (ползунок, 5 позиций)
| key | en | ru (из pf2ru-translation) |
|---|---|---|
| observed | Observed | Видимость |
| concealed | Concealed | Плохая видимость |
| hidden | Hidden | Спрятанность |
| undetected | Undetected | Необнаруженность |
| unnoticed | Unnoticed | Незамеченность |

Отношение направленное: «A для наблюдателя B» ≠ «B для A».

## Входит
- Только участники **активного боя** (combatants с токенами на текущей сцене).
- UI для ГМ с ползунками «наблюдатель → цель».
- Хранение состояний (рекомендация для всех прототипов, чтобы сравнение было честным):
  флаг на документе токена-цели `flags.pf2e-vision.visibility = { [observerTokenId]: state }`,
  отсутствие ключа = observed.
- Визуал на канвасе у игрока (относительно токенов, которыми он владеет; если их несколько —
  берётся самый «видимый» уровень): concealed — лёгкая прозрачность/индикатор, hidden — полупрозрачный
  с индикатором, undetected/unnoticed — токен не отображается.
- Механика в бросках: чистая проверка (СЛ 5 concealed, СЛ 11 hidden/undetected), застигнут врасплох
  (off-guard) — через средства системы pf2e.
- Автоматика по Stealth/Hide/Sneak/Seek с опорой на Workbench и Toolbelt.
- Локализация en + ru; русские термины брать из `pf2ru-translation`.
- Внешний вид в стиле pf2e (цвета, шрифты, иконки состояний системы).

## Не входит
- Токены вне боя.
- Совместная работа с PF2e Visioner / PF2e Perception (модуль самостоятельный).
- Расчёт видимости по освещению/линии взгляда — уровни выставляет ГМ или автоматика по броскам.

## Выбор пользователя (фаза 4)
- Основа: **окно-матрица** (prototypes/proto-1) с UI **«Кисть»** — макет: вариант C на холсте
  https://claude.ai/artifact/SpnTcP77ZC3QSruuPS7rj2 . Суть: палитра из 5 кистей сверху (+ горячие клавиши 1–5),
  клик или протяжка по ячейкам красит, клик по имени наблюдателя/цели красит строку/столбец, «Отмена».
  Локальная копия макета: `prototypes/mockup-brush.dc.html` (холст удалён).
- Решения фазы 5: автоматика Hide/Sneak/Seek — предложение ГМу с кнопкой «Применить»; провал чистой
  проверки = атака «промах»; off-guard влияет и на урон (Sneak Attack) в v1; v1 — только броски атаки;
  хранение — флаги на токене-цели; requires: только lib-wrapper (2026-10-11: зависимости от Workbench и
  Toolbelt убраны по решению пользователя; Toolbelt target-helper — необязательный источник целей Seek, если включён).
- **Вся автоматизация настраивается в параметрах модуля внутри Foundry, гибко**: режим отдельно для
  Hide/Sneak/Seek (выкл/предложение/авто), чистые проверки (вкл, СЛ, исход провала, чьи атаки), off-guard
  (попадание/урон), визуал игроков, очистка в конце боя, поведение матрицы. Выбор выше — значения по умолчанию.
- Сообщение чистой проверки: настройка видимости (публично / только ГМу), по умолчанию публично.
- Seek: есть явные цели — проверяются только они; нет целей — все скрытые от искателя участники боя.
- Матрица: подписи у кистей, имена в шапке столбцов.
  Ячейки — цветные плашки с иконкой и коротким названием; строки — наблюдатели, столбцы — цели.
- Добавить:
  - **подсветка на канвасе** — наведение на имя/ячейку подсвечивает токены (из proto-3);
  - **подсказка последствий** при наведении на ячейку: «Чистая проверка СЛ 11 · застигнут врасплох» и т.п.;
  - **сворачивание союзников** — переключатель скрывает ячейки PC↔PC и NPC↔NPC.
- Цвета уровней из макета: observed #2b2830, concealed #8fb8d4, hidden #e3a23b, undetected #b8483a, unnoticed #5a3d8c.
