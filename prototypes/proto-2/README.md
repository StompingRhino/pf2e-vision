# PF2e Vision — Proto 2: Tracker

Идея: в Combat Tracker у каждого участника (только ГМ) кнопка-глаз раскрывает блок «Как его видят» — ползунок из 5 уровней на каждого другого участника + групповые «для всех PC/NPC». В свёрнутом виде в строке мини-сводка скрытых состояний.

## Установка
Скопировать папку в `%LOCALAPPDATA%/FoundryVTT/Data/modules/pf2e-vision-proto-2/` (id модуля = имя папки; можно symlink), включить в мире pf2e (Foundry 14.364, pf2e 8.1.x; нужны `xdy-pf2e-workbench` и `pf2e-toolbelt`).

## Проверка по шагам
1. Сцена с токенами: 1–2 PC (владелец — игрок) и пара NPC; запустить бой, добавить всех.
2. ГМ: в трекере у NPC нажать глаз — раскрывается блок; перерисовка трекера (смена хода) не сворачивает его.
3. Поставить NPC для PC1 «Спрятанность»: в строке появилась иконка со счётчиком; ГМ на канвасе видит токен с подписью-индикатором.
4. Игрок PC1: токен NPC полупрозрачный с подписью «Спрятанность». «Плохая видимость» — лёгкая прозрачность. «Необнаруженность»/«Незамеченность» — токен пропал.
5. Групповой ползунок «Для всех PC» меняет всех PC сразу; при разных значениях показывает «Разные».
6. Флаг: `canvas.tokens.placeables[0].document.flags["pf2e-vision-proto-2"]` → `visibility: {observerTokenId: state}`.

## Заглушено
- Броски: `rollStub` в `scripts/main.mjs` (СЛ 5/11, застигнут врасплох) — не подключён.
- Автоматика Stealth/Hide/Sneak/Seek через Workbench/Toolbelt — только комментарий `// prototype:`.
- Несколько владельцев/групп — берётся самый видимый уровень; без проверки на пред-бой/смену сцены; при смене хода без `updateToken` канвас не пересчитывается.
- Не проверялось в запущенном Foundry (ядро локально не найдено, сверено с pf2e.mjs, чужими модулями и API-доками).

## Чем хуже других подходов
- Вставка в разметку pf2e-трекера хрупкая (`li.combatant`, `.combatant-controls`, `.token-name`); обновление pf2e/ядра может сломать.
- Трекер узкий: при 8+ участниках блок длинный, ползунки тесные.
- Взгляд цель-центричный: «что видит X про всех» (наблюдатель → цели) неудобно смотреть.
- Любое изменение флага перерисовывает весь трекер.
